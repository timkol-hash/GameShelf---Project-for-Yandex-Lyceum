# GameShelf

GameShelf — настольное приложение на Python для создания и управления личной коллекцией видеоигр. Приложение позволяет
добавлять игры, выбирать обложки, редактировать информацию, искать игры и управлять списком избранного.

## Возможности

- **Добавление игр** — создание карточек с названием, жанром и обложкой.
- **Обложки игр** — выбор изображения с компьютера.
- **Редактирование игр** — изменение названия, жанра и обложки.
- **Удаление игр** — удаление игр из коллекции с подтверждением.
- **Поиск** — поиск игр по названию.
- **Фильтрация по жанру** — отображение игр выбранного жанра.
- **Избранное** — добавление игр в избранное и удаление из него.
- **Отдельный просмотр избранного** — переключение между полной коллекцией и избранными играми.
- **Счётчик игр** — отображение количества игр в коллекции.
- **Локальная база данных** — сохранение информации между запусками приложения.
- **Тёмный интерфейс** — минималистичный дизайн в тёмных оттенках.

## Технологии

- **Python** — основной язык программирования.
- **PyQt6** — создание графического интерфейса.
- **SQLite** — хранение данных об играх.
- **Qt Style Sheets (QSS)** — оформление интерфейса.

## Установка и запуск

### 1. Получение проекта

Если проект размещён на GitHub, клонируй репозиторий:

```bash
git clone <URL_ТВОЕГО_РЕПОЗИТОРИЯ>
cd GameShelf
```

Вместо этого можно скачать проект и открыть его папку в PyCharm.

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активируй окружение в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Для командной строки Windows (CMD):

```bat
.venv\Scripts\activate.bat
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python main.py
```

Приложение использует SQLite для хранения данных. Убедись, что необходимые папки доступны для записи и база данных
инициализируется при запуске.

## Как пользоваться

1. Запусти GameShelf.
2. Нажми кнопку добавления игры.
3. Введи название и выбери жанр.
4. При необходимости выбери обложку с компьютера.
5. Сохрани игру — она появится в коллекции.
6. Используй поиск по названию и фильтр по жанру.
7. Добавляй игры в избранное с помощью кнопки на карточке.
8. Используй разделы «Моя коллекция» и «Избранное» для переключения между списками.
9. При необходимости редактируй или удаляй игры.

## Хранение данных

GameShelf использует SQLite для локального хранения информации об играх, включая:

- название;
- жанр;
- путь к обложке;
- состояние избранного.

Данные сохраняются между запусками приложения.

**Важно:** перед удалением файла `data/games.db` сделай резервную копию. В нём могут храниться все добавленные игры.

Пути к обложкам могут зависеть от расположения файлов на компьютере. Если переместить или удалить изображение,
приложение может перестать его отображать.

## Конфиденциальность

Коллекция хранится локально в базе данных на компьютере. Для использования приложения не требуется учётная запись.
