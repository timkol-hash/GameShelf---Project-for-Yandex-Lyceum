# GameShelf

**GameShelf** — настольное приложение на Python для создания и управления личной коллекцией видеоигр. Оно позволяет добавлять игры, выбирать для них обложки, редактировать информацию и быстро находить нужные игры с помощью поиска и фильтрации.

##  Возможности

-  **Добавление игр** — создание карточек с названием и жанром.
-  **Обложки игр** — выбор изображения с компьютера для каждой игры.
- ️ **Редактирование** — изменение названия и жанра, а также обновление обложки.
-  **Удаление** — удаление игр из коллекции.
-  **Поиск** — поиск игр по названию.
-  **Фильтрация по жанру** — просмотр игр выбранного жанра.
-  **Счётчик игр** — отображение количества игр в коллекции.
-  **Локальная база данных** — сохранение информации между запусками приложения.
-  **Тёмный интерфейс** — минималистичный дизайн в тёмных оттенках.

## Технологии

- **Python** — основной язык программирования.
- **PyQt6** — создание графического интерфейса.
- **SQLite** — хранение данных об играх.
- **Qt Style Sheets (QSS)** — оформление интерфейса.

##  Установка и запуск

### 1. Установи Python

Установи совместимую версию Python с официального сайта:

https://www.python.org/downloads/

### 2. Склонируй репозиторий

Если проект размещён на GitHub:

```bash
git clone <URL_ТВОЕГО_РЕПОЗИТОРИЯ>
cd GameShelf
```

Либо скачай проект и открой его папку в PyCharm.

### 3. Создай виртуальное окружение (рекомендуется)

```bash
python -m venv .venv
```

Активируй его в Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Если используешь командную строку Windows (CMD):

```bat
.venv\Scripts\activate.bat
```

### 4. Установи зависимости

```bash
pip install PyQt6
```

### 5. Запусти приложение

```bash
python main.py
```

При первом запуске приложение должно инициализировать локальную базу данных. Убедись, что папка `data/` существует или создаётся кодом приложения.

## Как пользоваться

1. Запусти GameShelf.
2. Нажми кнопку добавления игры.
3. Введи название и выбери жанр.
4. При необходимости нажми кнопку выбора обложки и выбери изображение на компьютере.
5. Сохрани игру — она появится в коллекции.
6. Используй поиск, чтобы найти игру по названию.
7. Выбирай жанр в фильтре, чтобы отобразить подходящие игры.
8. Используй кнопки редактирования и удаления на карточке, чтобы управлять коллекцией.

## Хранение данных

GameShelf использует SQLite для локального хранения информации об играх.

База данных содержит сведения, необходимые для отображения коллекции, включая названия, жанры и пути к обложкам.

**Важно:** перед удалением файла `data/games.db` сделай резервную копию — в нём могут храниться все добавленные игры.

Пути к обложкам могут зависеть от расположения файлов на компьютере. Если изображение переместить или удалить, приложение может перестать его отображать.

## Конфиденциальность

Данные коллекции хранятся локально на компьютере. Приложение не требует учётной записи для ведения коллекции.
